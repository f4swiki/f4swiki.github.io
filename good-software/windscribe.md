# Windscribe

Windscribe was our favourite way to bypass N4L's totalitarian regime between 19th August 2025 and 12th June 2026. We recommend using it instead of ProtonVPN on networks using [Fortinet](../spyware/fortinet.html).

## Using Windscribe

Before connecting, make sure to read our guide on [configuring Windscribe](../bypassing/configuring-windscribe.html) as the stock settings DO NOT work.

## Troubleshooting

**VPN is very slow (<50Kbps)**

* In Settings -> Connection, set "Packet Size" to 700.
